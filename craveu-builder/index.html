Card PNG

Choose your cover image and the builder embeds the card in a copy of it. Nothing is uploaded — it all happens in your browser. CraveU removes photorealistic character images, so use illustrated or anime-style art.

After you import
  1. Set the Rating: NSFW (R18) only if the avatar, introduction and greeting are themselves NSFW; otherwise Limited.
  2. Set Visibility (start as Private if you want to review it first) and set Character Definition to Hidden.
  3. Upload the avatar. SceneSnap, Gallery and VibeTrack have no JSON key and are set by hand.
  4. CraveU has no world-book field. If your bot relies on a lorebook, flatten the essentials into Scenario or keep it on a platform that supports one.
